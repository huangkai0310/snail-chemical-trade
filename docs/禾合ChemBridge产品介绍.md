## 一、产品概述

**禾合 (ChemBridge)** 是一个面向化工行业的大宗商品量化现货交易平台，采用"挂牌—摘牌"交易模式，为化工品贸易企业提供安全、透明、高效的线上撮合服务。

平台取名"禾合"——禾为谷物，象征实物贸易之本；合为聚合，寓意撮合买卖双方达成交易。英文名 **ChemBridge**，意为化工贸易的桥梁。

| 项目 | 信息 |
|------|------|
| 产品名称 | 禾合 (ChemBridge) |
| 所属公司 | 常州蜗牛化工技术开发有限公司 (Snail Chemical) |
| 产品类型 | B2B 化工大宗商品量化交易平台 |
| 交易模式 | 挂牌/摘牌 (Listing & Take) |
| 官网 | https://trade.snailchemical.com |
| API | https://api.snailchemical.com |

## 二、产品定位与价值

### 2.1 行业痛点

| 痛点 | 描述 |
|------|------|
| 信息不对称 | 化工品现货交易依赖传统渠道（电话、微信、展会），价格透明度低 |
| 交易效率低 | 询价—还价—签约—付款流程长，缺乏标准化电子交易工具 |
| 履约风险高 | 缺乏第三方保证金担保，违约成本低 |
| 价格发现难 | 缺乏连续、公开的成交数据，买卖双方无法快速了解市场公允价 |
| 数据孤岛 | 交易数据分散在个人沟通记录中，企业无法进行系统性市场分析 |

### 2.2 产品价值

```
化工贸易企业
    │
    ├── 发布挂牌（买/卖）──→ 平台撮合 ──→ 摘牌成交
    │                              │
    │                              ├── 保证金履约担保（10% 保证金率）
    │                              ├── 实时行情推送（WebSocket）
    │                              ├── K线图表分析（6种时间周期）
    │                              ├── 成交记录公开可查
    │                              └── 资金流水全程审计
    │
    └── 获得：透明定价 + 高效撮合 + 履约保障 + 数据分析
```

### 2.3 与竞品对比

| 维度 | 禾合 (ChemBridge) | 传统贸易 | 通用B2B平台 |
|------|-------------------|----------|------------|
| 交易模式 | 挂牌/摘牌，定向撮合 | 一对一议价 | 信息展示为主 |
| 价格透明度 | 实时行情，成交公开 | 价格不透明 | 报价滞后 |
| 履约保障 | 保证金担保（10%） | 无 | 无 |
| 数据分析 | K线图、盘口深度、价格走势 | 无 | 有限 |
| 行业专属性 | 化工品专用，交割周期定制 | — | 通用 |
| 交易效率 | 秒级撮合 | 数天 | 不涉及交易 |

## 三、核心功能

### 3.1 挂牌与摘牌交易

平台核心交易模式，区别于传统匿名竞价交易所，采用符合大宗商品现货监管要求的挂牌/摘牌模式。

**挂牌 (Create Listing)**：企业发布买卖意向，指定产品、价格、数量、交割周期、交割地点。

| 参数 | 说明 | 示例 |
|------|------|------|
| 交易方向 | BUY（求购）或 SELL（出售） | SELL |
| 产品 | 6种化工品 | 苯 (Benzene) |
| 价格 | 元/吨 | 7308.50 |
| 数量 | 吨 | 50 |
| 交割周期 | 现货 / YYMM中 / YYMM下 | 2607中（2026年7月中） |
| 交割地点 | 仓库/港口 | 张家港 |

**摘牌 (Take Listing)**：买方直接摘取卖方挂牌（或卖方摘取买方挂牌），定向一对一成交。

```
挂牌方                               摘牌方
  │                                    │
  │  ① 发布挂牌（价格、数量、交割期）    │
  │  ──────────────────────────────→   │
  │                                    │
  │                    ② 看到挂牌，点击摘牌
  │  ←──────────────────────────────   │
  │                                    │
  │  ③ 系统撮合                       │
  │  ├── 价格验证                      │
  │  ├── 自成交保护（同企业跳过）        │
  │  ├── 保证金冻结 + 结算              │
  │  └── 成交记录持久化                 │
  │                                    │
  │  ④ WebSocket 广播成交事件          │
  │  ←──────────→  ←──────────→       │
  │    双方确认     全员可见            │
```

**交易状态流转**：

```
OPEN（挂牌中）
  │
  ├── 部分成交 ──→ PARTIAL（部分成交）
  │    │
  │    ├── 继续成交 ──→ FILLED（全部成交）
  │    │
  │    └── 撤单 ──→ CANCELLED（已撤单）
  │
  └── 撤单 ──→ CANCELLED（已撤单）
```

### 3.2 撮合引擎

自研 Go 内存撮合引擎，核心特性：

| 特性 | 说明 |
|------|------|
| 价格优先 | 买盘价格越高越优先，卖盘价格越低越优先 |
| 时间优先 | 同价格下，先挂牌者优先成交 |
| 自成交保护 | 同一企业的买卖单不会相互成交 |
| 精度保护 | IEEE754 浮点精度修正，金额精确到分 |
| WAL 崩溃恢复 | 操作前写日志，重启后自动恢复订单簿状态 |

**数据结构**：
- 买盘：**最大堆** (MaxHeap)，价格从高到低排列
- 卖盘：**最小堆** (MinHeap)，价格从低到高排列
- 每个化工品独立维护一个订单簿

### 3.3 实时行情系统

**K线图表**：基于 TradingView lightweight-charts，支持 6 种时间周期。

| 周期 | 说明 |
|------|------|
| 1m | 1分钟 |
| 5m | 5分钟 |
| 15m | 15分钟 |
| 1h | 1小时 |
| 4h | 4小时 |
| 1d | 日线 |

**K线功能**：
- 蜡烛图 (Candlestick) + 成交量柱 (Volume)
- MA5 / MA10 / MA20 三条均线
- 十字光标悬浮详情面板（OHLC、涨跌幅、振幅、均线值）
- 面板智能翻转（鼠标靠近自动切换到对侧，避免遮挡数据）
- 响应式容器（ResizeObserver 自适应）

**盘口深度**：
- 买卖各五档深度展示
- 累计量条形可视化
- 最优买/卖价 + 价差
- 5 秒自动刷新

**成交明细**：
- 实时滚动成交记录（时间、价格、数量）
- 涨跌颜色编码（红涨绿跌）
- 5 秒自动刷新

**WebSocket 实时推送**：
- 成交事件秒级广播
- JWT 认证连接
- 断线 3 秒自动重连

### 3.4 资金账户与保证金系统

**账户模型**：

| 字段 | 说明 |
|------|------|
| 可用余额 (balance) | 可用于交易或提现的资金 |
| 冻结金额 (frozen) | 已冻结的保证金 |
| 累计入金 (total_in) | 历史总充值 |
| 累计出金 (total_out) | 历史总提现 |

**保证金机制**：

```
发布挂牌
  │
  ├── 冻结保证金 = 价格 × 数量 × 10%
  │   例：¥7308.50 × 50吨 × 10% = ¥36,542.50
  │
  ├── 成交 → 买方扣款（冻结→实付）、卖方收款
  │
  └── 撤单 → 保证金全额退还
```

**交易流水审计**：每笔资金变动记录完整前后快照：

| 流水类型 | 说明 |
|----------|------|
| DEPOSIT | 入金 |
| WITHDRAW | 出金 |
| FREEZE | 保证金冻结 |
| UNFREEZE | 保证金解冻 |
| TRADE_DEDUCT | 交易扣款（买方） |
| TRADE_INCOME | 交易收入（卖方） |
| REFUND | 退款 |

### 4.3 数据安全设计

| 维度 | 措施 |
|------|------|
| 传输安全 | TLS 1.2/1.3 加密 |
| 认证安全 | JWT HS256 签名，72 小时过期，缺失密钥时拒绝启动 |
| 密码安全 | bcrypt 哈希存储，不可逆 |
| 并发安全 | 数据库行级锁 (SELECT FOR UPDATE)，事务保证 |
| 精度安全 | 金额精确到分，浮点运算使用 roundDecimal2 修正 |
| 防刷保护 | IP 级别速率限制（认证 2rps，业务 10rps） |
| 自成交保护 | 撮合引擎检测同企业买卖单自动跳过 |
| 崩溃恢复 | WAL 预写日志，重启后自动重建内存订单簿 |
| 审计追踪 | 每笔资金变动记录完整 before/after 快照 |

## 五、数据安全与合规

### 5.1 合规设计

平台在设计上严格遵守大宗商品现货交易的监管要求：

1. **挂牌/摘牌模式，非匿名竞价** — 采用定向撮合而非匿名集中竞价，不构成"交易所"特征
2. **强制实物交割** — 每笔挂牌必须指定交割周期和交割地点，不支持净额结算
3. **无标准化合约** — 挂牌方可自定义价格、数量、交割条件，非标准化产品
4. **保证金为履约担保** — 10% 保证金率，非杠杆交易保证金
5. **企业实名制** — 用户注册需提供企业名称、联系方式等实名信息

### 5.2 保证金计算示例

| 场景 | 挂牌价 | 数量 | 保证金率 | 冻结金额 |
|------|--------|------|----------|----------|
| 卖苯 | ¥7,308.50 | 50吨 | 10% | ¥36,542.50 |
| 买丙烯 | ¥6,500.00 | 100吨 | 10% | ¥65,000.00 |
| 卖丙酮 | ¥5,200.00 | 30吨 | 10% | ¥15,600.00 |
