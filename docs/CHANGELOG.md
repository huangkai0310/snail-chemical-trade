# 产品迭代日志

> 本文档记录禾合 (ChemBridge) 化工量化交易平台所有产品功能、架构、接口的变更历史。
> 每次发版或重大功能上线后，按**时间倒序**在本文件追加一条记录，并在 `禾合ChemBridge产品介绍.md` 中同步更新对应章节。

---

## [v1.0] — 2026-06-28 基础版上线

### 新增功能
- ✅ 用户认证系统：企业注册、登录、JWT 认证、bcrypt 密码加密
- ✅ 6 种化工品支持：苯、丙烯、苯酚、丙酮、异丙醇、MIBK
- ✅ 挂牌/摘牌交易：发布挂牌、定向摘牌、撤单、状态流转 OPEN→PARTIAL→FILLED/CANCELLED
- ✅ 撮合引擎：价格优先 + 时间优先 + 自成交保护 + 浮点精度修正
- ✅ WAL 崩溃恢复：操作前写日志，重启自动恢复内存订单簿
- ✅ K线图表系统：6种时间周期（1m/5m/15m/1h/4h/1d）+ 成交量柱 + MA5/10/20 均线
- ✅ K线十字光标悬浮详情面板：OHLC + 涨跌幅 + 振幅 + 均线值，智能翻转防遮挡
- ✅ 盘口深度：买卖五档 + 累计量条形 + 价差显示
- ✅ 成交明细：实时滚动 + 涨跌颜色编码（红涨绿跌）
- ✅ 资金账户体系：余额/冻结/入金/出金/完整交易流水审计
- ✅ 保证金系统：10% 保证金率，挂牌冻结、撤单退还、成交结算
- ✅ WebSocket 实时推送：JWT 认证连接 + 3秒断线重连
- ✅ 我的交易：个人挂牌/成交 Tab 切换
- ✅ 交易终端 UI：暗色三栏布局 + 可拖拽侧栏 + 暗色专业主题
- ✅ 全局价格展示统一：去掉千分位逗号，格式统一为 `¥7308.5` 风格

### 技术参数
- 后端：Go + Gin，PostgreSQL 16，撮合引擎自研（container/heap）
- 前端：Next.js 15 + TypeScript + Tailwind CSS + lightweight-charts
- 部署：腾讯云 4C8G + Nginx + Cloudflare + systemd
- 安全：JWT 72h 过期、IP 速率限制、数据库行级锁、WAL 预写日志

### 已知限制
- 仅支持 6 种基础化工品
- 单服务器部署，未做微服务拆分
- 移动端适配未完成（仅 Web 端）
- 无数据导出与 API 订阅服务

## 附录：更新操作指南

### 版本号规则（语义化版本）
- **主版本号**：不兼容的架构变更 / 合规级别变更（如 v1 → v2）
- **次版本号**：新增功能 / 重大接口变更（如 v1.0 → v1.1）
- **修订号**：bug 修复 / 文案调整 / 性能优化（如 v1.0.0 → v1.0.1）

### 发版后更新步骤
1. 在本文件**顶部**追加一条 `[vX.Y.Z] — YYYY-MM-DD` 记录
2. 同步更新 `禾合ChemBridge产品介绍.md` 中对应章节
3. 如有 API 变更，同步更新**六、API 接口**章节
4. 如有数据库变更，同步更新产品介绍文档中的数据库相关描述
